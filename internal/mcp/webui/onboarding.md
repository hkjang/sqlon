# sqlon 온보딩 가이드

**sqlon**은 PostgreSQL·MySQL·MariaDB·Oracle을 관찰하고, 진단하고, 승인된 변경으로만 손대는 **AI Database Operations Platform**입니다. 자연어 질의(SQL Lab)와 MCP 도구도 같은 안전장치를 거칩니다. 이 문서는 처음 쓰는 분을 위한 빠른 안내입니다.

## 1. 5분 시작

1. **설정 › DB 연결**에서 DB 프로파일을 등록하고 **접속 테스트**로 초록 표시를 확인합니다. 계정은 읽기 전용 모니터링 계정을 쓰세요(PostgreSQL은 `GRANT pg_monitor`).
2. **모니터링 › 운영 현황**에서 모든 DB의 상태와 위험 순위를 봅니다. 행의 **바로가기**로 그 DB의 세션·워크로드·점검·경보로 이동합니다.
3. **모니터링 › 예방 경보**에서 디스크 고갈 예측을 확인합니다. DB 연결 화면에서 **저장공간 한도**(볼륨 크기)를 넣어야 "며칠 뒤 가득 차는지"가 계산됩니다. 알림 채널(Mattermost·Slack 웹훅)은 예방 경보 › 설정에서 지정합니다.
4. 필요하면 **SQL Lab**에서 업무 질문을 SQL로 준비하고 **검증 → 실행계획 → 미리보기 → 실행** 순으로 읽기 전용 실행합니다.

## 2. 화면 이동

- 왼쪽 메뉴는 업무 단위로 묶여 있습니다 — **모니터링 · 진단·점검 · 변경·작업 · SQL Lab · 메타데이터 · 설정**. 그룹 이름을 눌러 접고 펼치며, 상태는 기억됩니다.
- **Ctrl+K**(macOS는 ⌘K)로 어디서든 **빠른 이동**을 엽니다. 화면 이름이나 기능(예: "경보", "블로킹", "권한")으로 찾고 Enter로 엽니다. 검색어가 없으면 최근 방문한 화면이 먼저 나옵니다.
- 화면 오른쪽 위 **가이드**(또는 **?** 키)로 그 화면의 사용법을 봅니다.
- 한 화면에서 고른 DB는 다른 화면에서도 그대로 선택됩니다.
- 메뉴 아래의 테마 버튼으로 **시스템 · 라이트 · 다크**를 바꾸고, 메뉴 위의 접기 버튼으로 아이콘만 보이는 좁은 메뉴를 씁니다.
- **예방 경보** 메뉴의 빨간 숫자는 아직 아무도 확인하지 않은 긴급 경보 수입니다(브라우저 탭 제목에도 표시). **변경 관리**의 숫자는 승인 대기 계획 수입니다.

## 3. 운영 워크플로

- **관찰**: 운영 현황 → 세션·잠금(블로킹 그래프) → 워크로드(QPS·TPS·Top SQL) → 객체·용량 → 복제·백업.
- **예방**: 예방 점검이 wraparound·블로트·WAL 아카이브 실패·버려진 복제 슬롯 같은 잠복 위험을 찾고, 예방 경보가 이를 원인과 함께 알립니다.
- **변경 통제**: 모든 쓰기 작업은 **변경 관리**의 변경계획(실행·검증·보상 문장)으로 만들고 **제출 → 승인 → 실행**을 거칩니다. 예방 경보 상세의 **수정안 만들기**도 같은 흐름의 초안을 만듭니다.
- **DBA 콘솔**: 사용자·권한·설정 같은 권한 있는 작업 전용입니다(dba/admin). 모든 작업이 감사 로그에 남습니다.

## 4. 메타데이터 관리

- **자동 수집**: `run_metadata_sync`로 원천 DB의 물리 모델을 수집하고 `apply_metadata_sync`로 카탈로그에 반영합니다(기존 설명 보존).
- **의미 보강**: `suggest_semantic_metadata`·`suggest_model_candidates`가 논리명·설명·코드사전·지표·관계 **후보**를 만듭니다.
- **검토 승인**: **메타 검토**에서 후보를 승인·반려하고, 승인분을 반영합니다.
- **품질 관리**: **메타 품질**에서 7차원 점수·등급·릴리스 게이트를 확인합니다.
- **프로파일 카탈로그**: DB마다 독립 카탈로그 워크스페이스를 두고, 요청 단위로 `profile`을 지정해 여러 DB를 질의합니다.
- **OpenMetadata**: 전사 카탈로그와 설명·PII·용어집을 양방향 연동합니다(빈 필드에만 반영).

## 5. 운영·보안

- **감사 로그**: 모든 도구 호출·관리 작업이 해시 체인 감사 로그에 남아 변조를 탐지합니다.
- **메트릭**: `/metrics`(Prometheus)에서 저장공간 예측·경보·도구 호출량을 노출합니다.
- **권한**: 로그인(메타 DB) 모드에서 관리 작업은 admin, 변경·DBA 작업은 dba 역할이 필요합니다. 단독 모드에서는 상단의 **관리 토큰** 버튼으로 토큰을 입력합니다.
- **MCP 키**: LLM 클라이언트·스크립트는 로그인 대신 **설정 › MCP 키**에서 발급한 키를 씁니다.
